# Welcome to the Global MCP Control Plane Wiki

The **Global MCP Control Plane** is a robust local dashboard and daemon designed for developers and AI agents. It completely streamlines discovering, installing, configuring, and managing Model Context Protocol (MCP) servers locally without the friction of manual configuration or GitHub cloning.

## Quick Links
- [Architecture & Design](Architecture.md)
- [How to Add an MCP Server](Adding-an-MCP-Server.md)
- [Building Client Adapters](Client-Adapters.md)

## Core Philosophy
1. **Local First**: Your MCP configurations remain entirely on your local machine.
2. **Safe & Verifiable**: All installations are mapped out into isolated directories, sandboxed, and easily reversible.
3. **Agent Friendly**: The entire stack is built to be manageable both by humans via the React Dashboard and by autonomous agents via the local daemon API.
