# Support

## Need Help?

If you have a question, issue, or feature request regarding Global MCP Control Plane, here is how you can get support:

### 1. Check the Documentation
Before opening an issue, please check the following resources:
- [README.md](./README.md) for setup instructions.
- [ARCHITECTURE.md](./ARCHITECTURE.md) for system design.
- [SECURITY.md](./SECURITY.md) for security considerations.

### 2. Search Existing Issues
Your issue might have been reported or resolved already. Please [search the issue tracker](https://github.com/blackwh1te/AI-GLOBAL-SKILLS/issues) before submitting a new one.

### 3. Open a New Issue
If you found a bug or have a feature request, please open a new issue. Provide as much context as possible, including:
- Steps to reproduce
- Operating system and Node/Bun version
- Relevant logs from `global-mcp logs <id>`

## Security Vulnerabilities
If you discover a security vulnerability, **do not** open a public issue. Please read [SECURITY.md](./SECURITY.md) for instructions on how to privately report it.
