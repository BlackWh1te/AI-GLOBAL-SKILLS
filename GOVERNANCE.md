# Project Governance

## Maintainers
The Global MCP Control Plane is maintained by the core team. Maintainers have write access to the repository and are responsible for reviewing pull requests, managing issues, and cutting releases.

## Contributions
Anyone can contribute to the project! See [CONTRIBUTING.md](./CONTRIBUTING.md) for details on how to get started. Significant architectural changes should be proposed via an issue before submitting a PR.

## Code of Conduct
All interactions must adhere to our [Code of Conduct](./CODE_OF_CONDUCT.md).

## Decision Making
Decisions are made by consensus among the maintainers. If consensus cannot be reached, the project lead will make the final decision.
